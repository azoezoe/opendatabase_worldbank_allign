# 世界銀行 Data360 × 台灣資料對應盤點

以世界銀行 Data360 的指標為標準，逐項盤點台灣有沒有對應的資料、資料集在哪裡、完整起迄，以及建議由 RD 爬取還是直接做索引；歐噴資料庫已上架的資料集一併對應。

## 狀態定義

| 狀態 | 意思 | 建議 |
|---|---|---|
| 直接對應 | 台灣官方有同一指標；定義或計價基準不同處寫在「對應或計算方式」 | 索引 |
| 可計算 | 台灣沒有直接公布，但可由列出的台灣資料集計算 | 索引來源表，由 RD 計算 |
| 近似對應 | 台灣有概念接近、但定義或方法不同的官方資料（例如貪腐控制對應廉政署「廉政民意調查」） | 索引並註明差異 |
| 待確認 | 台灣可能有資料，但未確認是否公布或口徑 | 確認後再決定 |
| 沒有 | 台灣沒有官方同類統計（國際評比、問卷、模型推估等） | 不收 |
| 不適用 | 指標只適用特定國家群（受援國、IDA 借款國、DHS／MICS 調查國等）或制度上不存在 | 不收 |

「台灣資料集」一律是台灣官方或台灣機構的資料。國際資料庫（Data360、IMF WEO、WGI、Findex 等）即使有台灣數值，也只列在「國際參考來源」欄，不當作台灣資料集。

## 取得方式（每個台灣來源）

| 取得方式 | 意思 |
|---|---|
| 已上架 | 歐噴資料庫已有，以歐噴 API 查詢確認（2026-11-10），不用處理 |
| 部分已上架 | 歐噴只有部分數列、期間或縣市級資料，其餘仍需取得 |
| 索引 | 有固定網址，一個檔案就含歷年資料，直接做索引文件 |
| RD 爬 | 查詢系統要選參數才能下載（如主計總處總體統計資料庫）、只放最新一期，或要逐期下載很多檔案再彙整 |
| 人工整理 | 非逐年調查報告、法規條文 |
| 需申請 | 需向中研院 SRDA 申請原始資料 |

各盤點 HTML 上方的「需要抓」來源表，只列歐噴還沒有（或只有部分）的台灣資料集，依索引、RD 爬、人工整理／需申請分區；`sources/taiwan_sources.csv` 有每個來源的取得方式、理由與歐噴現況。

## 範圍與批次

Data360 除 WDI 外另有 170 個子資料庫、8,288 項指標；其中 353 項與 WDI 同一指標，沿用 WDI 結果。

| 批次 | 內容 | 約略項數 |
|---|---|---|
| PR 0 | 本架構、WDI 盤點、台灣來源總表 | 1,523 |
| PR 1 | Data360 已有台灣的國際評比與調查（WGI、Findex、LPI、WBL、WEF、V-Dem、Freedom House、BTI、Polity、企業調查等） | 1,500 |
| PR 2 | Data360 已有台灣的 IMF 與其他資料庫（IFS、WEO、CPIS、CDIS、匯率、OECD、FAO、EDGAR、人力資本、水資源、FinData 等 43 個） | 1,309 |
| PR 3 | 世界銀行主題資料庫（性別、健康、ESG、國際債務、氣候、人力資本、UHC） | 780 |
| PR 4 | IMF 國際收支（IMF_BOP） | 1,129 |
| PR 5 | IMF 政府財政 GFS 系列 | 650 |
| PR 6 | IMF 金融（金融健全、外匯準備、金融普及） | 450 |
| PR 7 | 教育（WB_EDSTATS） | 1,072 |
| PR 8 | 其餘小型資料庫（治理、產業、氣候、OECD、FAO 等） | 1,000 |

WDI 在 Data360 搜尋索引顯示 1,546 項；實際下載的指標清單為 1,523 項，本盤點以 1,523 項為準。
